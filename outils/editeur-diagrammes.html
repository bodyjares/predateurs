Éditeur de diagrammes

Dessine les exercices et les situations du système de jeu. Tes changements s'affichent tout de suite dans la banque et le planificateur.

    Fichier

    Mode d'emploi
    • Placer : choisis X, O, G, C, Cône ou Rondelles, puis clique sur la glace (autant de fois que tu veux).
    • Tracer : choisis un type de trajet, clique pour chaque point, puis double-clique (ou Entrée) pour terminer. Si tu commences sur un joueur, le trajet part de lui. Une passe ou un tir est une ligne droite : 2 clics suffisent.
    • Déplacer : avec « Choisir », glisse un élément. Déplacer un joueur déplace aussi le début des trajets qui partent de lui.
    • Courbes : la ligne passe par tous ses points. Sélectionne un trajet, double-clique sur la ligne pour ajouter un point, puis glisse-le pour courber. Double-clique sur un point pour le retirer. Les passes et les tirs restent droits.
    • Synchroniser : sélectionne un trajet, clique « Synchroniser avec… », puis clique le trajet principal. Dans l'animation, le premier partira et finira exactement en même temps que le second (sa vitesse s'ajuste).
    • Étiquettes : un texte encadré pour une consigne (ex. : « MUR! »). Dans le panneau, tu choisis les étapes où elle apparaît pendant l'animation.
    • Fichier : « Charger un fichier » reprend un diagrammes-donnees.js déjà enregistré (utile si tu changes de navigateur ou d'ordinateur). Il remplace tous les diagrammes affichés.
    • Nouveau diagramme : « ＋ Nouveau » crée un diagramme libre, qui n'est rattaché à aucun exercice. Il apparaît dans la liste sous « Mes diagrammes ».
    • Étapes : avec « ① Étape », clique sur les trajets dans l'ordre (1, 2, 3…). Clique un numéro pour le changer ou le supprimer, glisse-le pour le déplacer le long de la ligne.
    • Suppr efface la sélection (ou le point choisi), les flèches la déplacent (Maj = plus loin), Cmd/Ctrl+D duplique, Cmd/Ctrl+Z annule.
